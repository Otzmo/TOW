# Arbeitsweise

- Antworten auf Deutsch, direkt und knapp.
- Die Seite ist `index.html`; sie läuft über GitHub Pages von `main` und als Artefakt „OTZMO-TOW“ (https://claude.ai/artifact/ErK94oEjWKCDTAmV7XoD8b).

## Änderungen

1. Jede Änderung zuerst im Artefakt OTZMO-TOW zeigen (die geänderte `index.html` dorthin veröffentlichen). Vorher nichts auf GitHub tun – kein Commit, kein Push, kein Branch, kein Pull Request.
2. Erst wenn der Nutzer „push“ schreibt: alles direkt auf `main` committen und pushen, `index.html` wird dabei überschrieben. Kein Feature-Branch, kein Pull Request.

## Commits

- Autor ist immer der Nutzer, damit die Commits in seinem GitHub-Profil zählen:
  `git -c user.name="Otzmo" -c user.email="57353152+Otzmo@users.noreply.github.com" commit …`
- Claude steht nur als Co-Autor in der Commit-Nachricht (`Co-Authored-By: …`).
